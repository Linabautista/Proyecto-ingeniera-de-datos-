# Tablero GEIH - SQL

Tablero de Power BI del proyecto Del microdato al indicador.

Base de datos: MySQL
Base utilizada: proyecto_geih
Vista principal: v_indicador_vigente

El tablero presenta indicadores laborales calculados a partir de la GEIH del DANE.

Este tablero utiliza el mismo diseño del tablero MongoDB, pero obtiene sus datos de la base relacional MySQL.

Archivo principal: Tablero_GEIH_SQL.pbix
