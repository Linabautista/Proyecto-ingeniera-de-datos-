# Del microdato al indicador

Base de datos relacional con indicadores del mercado laboral colombiano, construida a partir de los microdatos de la Gran Encuesta Integrada de Hogares (GEIH) del DANE. Es el proyecto de la clase de Ingeniería de Datos.

**Equipo:** Lina Bautista, Jessica Gil, Mariana Ussa y Jorge Reza.

Este repositorio contiene el **Entregable 2**: la fase relacional (diseño, base de datos en SQL y preparación de los datos en Python).

## Contenido del repositorio

```
Entregable 2/
├── Entregable_2_Proyecto_IngDatos.pdf   Documento del entregable
├── Diccionario BD.xlsx                  Diccionario de datos (una hoja por tabla)
├── Diagramas/                           Diagramas de clases, MER, modelo lógico y modelo físico
├── Scripts/
│   ├── preparar_geih.ipynb              Cuaderno de Python que prepara los datos
│   └── Script_BD_SQL_FINAL.sql          Script completo de la base de datos (MariaDB/MySQL)
├── Microdatos GEIH/                     Archivos originales del DANE, por año y mes
└── Datos para BD/                       CSV ya procesados, listos para cargar en SQL
```
